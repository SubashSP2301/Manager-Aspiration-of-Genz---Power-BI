# 📌 Project: Manager Aspirations of Gen Z (Power BI Dashboard)
Tools Used: Power BI, DAX, Data Modeling, Interactive Visuals, Filters

🚀 Description:
Built an interactive Power BI dashboard to explore Gen Z’s interest in becoming future managers 👨‍💼👩‍💼. Analyzed real-time student data to uncover trends in leadership goals, preferred work styles, and motivation for management roles.

📊 What I Did:

Cleaned and transformed raw student data using Power BI tools ⚙️

Designed dynamic visuals with slicers for gender, city, and career level 🎨

Used DAX to create KPIs like Manager Interest %, Confidence Level, and Role Readiness 📈

Added filters for easy exploration by educators and stakeholders 🧭

💥 Impact:
Helped trainers and education planners identify leadership-focused students early and design better mentorship and career path programs. Supported data-driven decisions in talent development.
